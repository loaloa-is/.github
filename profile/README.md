# Loaloa

**Archive Intelligence for enterprise media.**

Loaloa develops Studio, an AI-native media platform for organizations with large video, audio, image and document archives.

Most enterprise archives are overflowing. The problem is not that content is missing — it is that no one can find, trust, reuse or safely publish what already exists. Loaloa turns institutional media archives into searchable, governed and publishable intelligence.

We are building one platform for the full lifecycle: ingest, enrichment, search, access control, publishing and distribution. AI is native to the platform, not bolted on afterwards.

## What we build

Studio combines cloud media asset management, online video infrastructure and multimodal AI search into one operating layer.

- **Archive** — ingest, store and organize video, audio, images, documents, live streams and legacy media
- **Enrich** — generate transcripts, subtitles, translations, summaries, image labels, document text and metadata
- **Understand** — search across speech, documents, images and structured metadata using natural language
- **Control** — manage tenants, channels, roles, permissions, audit trails, compliance, enterprise identity, access control and publishing workflows
- **Activate** — publish to websites, streaming surfaces, social platforms, customer portals and AI-agent workflows

## Category

We call this category **Archive Intelligence**.

It sits between cloud MAM, online video platforms, enterprise search and AI video intelligence. Built for organizations that operate like media companies but cannot rely on fragmented storage, generic search or one-format tools.

The archive becomes a reasoning layer, not just a storage layer.

## Architecture

Loaloa is built as cloud-native infrastructure for enterprise media operations.

- Multi-tenant content model for video, audio, images, documents, channels, tags, clips and derivatives
- Channel-level access control that AI search and retrieval must respect
- Event-driven ingest and processing pipelines using AWS Step Functions, Lambda and EventBridge
- Video processing with AWS MediaConvert, HLS output and CloudFront-based playback
- Live streaming and recording workflows using AWS IVS
- Search and retrieval powered by OpenSearch across metadata, transcripts and documents
- AI enrichment using speech-to-text, image analysis, document parsing, summaries, entities, topics and subtitles
- GraphQL surfaces for both internal administration and customer-facing distribution
- Identity and access built around Cognito, tenant roles and channel memberships
- Infrastructure-as-code on AWS with Terraform
- MCP-connected intelligence layer for AI agents, Claude and custom tools

## Trust, Security & Compliance

Loaloa is built for organizations that need to trust their archive infrastructure.

We treat compliance, access control and data protection as core product architecture. Not procurement paperwork added at the end.

- Hosting in AWS data centres within the European Economic Area
- Data encrypted in transit with TLS and at rest with AES-256
- Tenant isolation, role-based permissions and channel-level access control
- Support for two-factor authentication and enterprise identity workflows
- Active Directory / Microsoft Entra ID integration for complex user management at institutional scale
- Audit trails for logins, access and key user actions
- Security monitoring, incident logging and documented incident response
- GDPR-aligned data processing, including processor agreements and documented controller instructions
- Configurable access models for public, private, internal and subscriber-only content
- Customer ownership of data, with export, retention and secure deletion workflows
- Work towards ISO/IEC 27001-aligned information security management

For customers with large teams, Loaloa can connect archive access to existing organizational identity structures — so permissions, roles and content visibility can reflect the way the institution already works.

## Design principles

- **AI-native, not AI-added** — enrichment, search and activation are part of the platform architecture
- **Trust is the product** — compliance, permissions, auditability and data protection are designed into the operating layer
- **Access control goes all the way down** — search, answers and suggestions should only expose what the user is allowed to see
- **Enterprise identity matters** — Loaloa is designed to work with complex organizations, including Active Directory / Entra ID and SSO-based user management
- **Evidence matters** — answers should point back to source material, timestamps, pages and documents
- **Multimodal by default** — video, audio, images, documents and live streams belong in the same governed archive
- **Built for small-language markets** — including Icelandic and other languages that are often underserved by generic media tools
- **Enterprise-ready infrastructure** — tenant isolation, auditability, governance, repeatable deployment and provider flexibility
